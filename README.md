# 智慧流程圖產生器 V1.9.8.1
A4 Word & PNG Label Hotfix

## Word 版本輸出
Word 輸出固定使用 A4：

- A4 直式：210 × 297 mm
- A4 橫式：297 × 210 mm
- 系統依流程圖寬高比例自動選擇直式／橫式
- 不使用自訂紙張高度
- 約 5 mm 邊界
- 流程圖在 A4 可用範圍內等比例放大
- 水平置中
- 垂直靠上

輸出格式仍為真正 `.docx`。
