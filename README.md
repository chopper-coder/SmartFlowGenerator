# 智慧流程圖產生器 V1.9.5.3
PDF Readability & High Resolution Hotfix

## 修正原因

舊版 PDF 雖然標示 150 DPI，但流程圖會先依 SVG 原始像素大小轉成點陣圖片，
再放大貼到 A4 Canvas。

因此：
- 長流程在「單頁縮放」時文字會很小。
- PDF 放大後，實際來源仍是低解析點陣圖，文字會糊。

## V1.9.5.3 修正

### 1. 預設改成閱讀清晰模式
- 預設：閱讀清晰（自動多頁）
- 單頁全圖仍保留，但明確標示「可能字較小」
- 預設頁邊界改為 6 mm，增加流程圖可用空間

### 2. PDF 解析度可選
新增：
- 180 DPI 標準
- 240 DPI 清晰
- 300 DPI 超清晰（預設／推薦）

大型流程仍會依頁數自動啟用記憶體保護。

### 3. 真正高解析 SVG → PDF
PDF 每一頁會依該頁實際輸出像素尺寸，
直接由 SVG 重新渲染。

不再：
低解析 SVG 圖片 → 放大 → PDF

改為：
SVG → 該頁 240/300 DPI 實際尺寸 → PDF

因此文字、框線、箭頭放大查看會清楚很多。

### 4. PNG 同步修正
PNG 2× / 4× 現在也是真正依指定像素重新渲染 SVG，
不再只是放大低解析圖片。

### 5. PDF 預設最高壓縮品質
- 預設 0.97
- 降低文字邊緣的 JPEG 壓縮模糊

## 保留
- 11 組流程範例

- 單頁 / 多頁 PDF

- 右側原始預覽設計
- SVG / PNG / JSON
